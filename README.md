# Scientific Computing & Numerical Methods in Python

A collection of Python scripts covering numerical methods, linear algebra, root-finding, interpolation, optimization, and ordinary differential equations for the `scientific` repository.

## Repository Files

* `Bisection and fixed-point methods.py` — Root-finding methods using bisection and fixed-point iteration.
* `Curve fitting and approximation.py` — Fitting curves and approximating functions to data.
* `Eigenvalues and eigenvectors.py` — Computing eigenvalues and eigenvectors.
* `Floating-point arithmetic and numerical errors...py` — Exploring floating-point representation and numerical error.
* `Gaussian elimination and LU decomposition.py` — Solving linear systems via Gaussian elimination and LU decomposition.
* `Interpolation.py` — Interpolating data points.
* `Iterative methods for linear systems.py` — Iterative approaches for solving linear systems.
* `Mathematical functions and vectorization.py` — Working with mathematical functions and vectorized operations.
* `Matrix algebra and operations.py` — Core matrix operations and linear algebra routines.
* `Newton-Raphson and Secant methods.py` — Root-finding using Newton-Raphson and secant methods.
* `NumPy arrays and numerical computation.py` — Numerical computations using NumPy arrays.
* `Numerical ODE solutions using SciPy.py` — Solving ordinary differential equations with SciPy.
* `Numerical differentiation.py` — Numerical approximations of derivatives.
* `Numerical optimization.py` — Numerical optimization routines.
* `Ordinary differential equations using Euler's m...py` — Solving ordinary differential equations using Euler's method.
* `Polynomial and nonlinear equation solving.py` — Solving polynomial and nonlinear equations.
